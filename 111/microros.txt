开始：
一  。获取micro_ros_stm32cubemx_utils文件
git clone https://github.com/micro-ROS/micro_ros_stm32cubemx_utils.git
cd micro_ros_stm32cubemx_utils
git checkout humble
git clone --branch humble https://github.com/micro-ROS/micro_ros_stm32cubemx_utils.git


二  。新建stm32cubeide项目并设置
1   配置ros
2   配置cdc

三  。项目属性设置
1   复制micro_ros_stm32cubemx_utils文件夹到项目主路径下
2   添加文件四个文件（/home/zrc/micro_ros_stm32cubemx_utils/extra_sources/）到src下。
custom_memory_manager.c内存
microros_allocators.c内存
microros_time，以及cdc时间
usb_cdc_transport.c我使用的传输方式

3   编译拉取（科学）Project -> Settings -> C/C++ Build -> Settings -> Build Steps->Pre-build steps=
docker pull microros/micro_ros_static_library_builder:humble && \docker run --rm -v ${workspace_loc:/${ProjName}}:/project \--env HTTP_PROXY=http://127.0.0.1:7890 \--env HTTPS_PROXY=http://127.0.0.1:7890 \--env MICROROS_LIBRARY_FOLDER=micro_ros_stm32cubemx_utils/microros_static_library_ide \microros/micro_ros_static_library_builder:humble

docker pull microros/micro_ros_static_library_builder:humble && docker run --rm -v ${workspace_loc:/${ProjName}}:/project --env MICROROS_LIBRARY_FOLDER=micro_ros_stm32cubemx_utils/microros_static_library_ide microros/micro_ros_static_library_builder:humble
4   （头文件路径）Project -> Settings -> C/C++ Build -> Settings -> Tool Settings Tab -> MCU GCC Compiler -> Include paths=
micro_ros_stm32cubemx_utils/microros_static_library_ide/libmicroros/include
/home/zrc/STM32CubeIDE/workspace_1.16.0/405/micro_ros_stm32cubemx_utils/microros_static_library_ide/libmicroros/include
5   （库路径）Project -> Settings -> C/C++ Build -> Settings -> MCU GCC Linker -> Libraries   Library search path (-L)=
micro_ros_stm32cubemx_utils/microros_static_library_ide/libmicroros
/home/zrc/STM32CubeIDE/workspace_1.16.0/405/micro_ros_stm32cubemx_utils/microros_static_library_ide/libmicroros
6   （库名）Project -> Settings -> C/C++ Build -> Settings -> MCU GCC Linker -> Libraries   Libraries (-l)=
microros
